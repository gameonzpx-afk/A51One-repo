---

## ⚡ Sobre o A51One
O **A51One** é um projeto independente focado em entregar um sistema limpo, unificado e com o máximo de desempenho para o **Samsung Galaxy A51 (a51 / Exynos 9611)**. 

Toda a compilação do código é feita direto nos servidores da nuvem usando o **GitHub Actions**, porque meu computador só tem 33 GB de espaço livre e explodiria se eu tentasse compilar nele! 😂
